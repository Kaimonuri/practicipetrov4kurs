# Prac2 -> доработка по ТЗ «Django store 3»

Проект продолжает мебельный интернет-магазин из практических работ 1–2.

## Запуск на Windows 11

```cmd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py setup_lab_admin
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/

Админка: http://127.0.0.1:8000/admin/

По заданию администратор создаётся командой `python manage.py setup_lab_admin`:

- логин: `Lab16`
- пароль: `Prac4`

## Что добавлено в третьей доработке

- строгая регистрация: логин, ФИО, телефон, email, пароль;
- клиентская проверка полей регистрации в реальном времени;
- способ доставки, дата доставки и способ оплаты при checkout;
- отзывы только после статуса заказа «Завершено»;
- адаптация интерфейса под смартфоны 390x844 и микроанимации;
- карточное отображение заказов в Django Admin и новые статусы;
- избранное для авторизованных пользователей;
- процентные и фиксированные промокоды;
- локальное кеширование каталога на 5 минут с автоматическим сбросом при изменениях;
- `.gitignore` без `.venv`, секретов, `media`, БД и собранной статики;
- подготовка настроек для работы за Cloudflare.

## Промокоды

Промокод создаётся в админке в разделе «Промокоды». Можно выбрать процентную или фиксированную скидку, период действия и активность.

## Отзывы

Чтобы пользователь смог оставить отзыв, администратор должен открыть заказ и установить статус «Завершено». После этого форма отзыва станет доступна на страницах товаров из этого заказа.
