# Cloudflare для практической работы

Локально Cloudflare не требуется. В проекте подготовлены `STATIC_ROOT`, `SECURE_PROXY_SSL_HEADER` и `USE_X_FORWARDED_HOST`, чтобы сайт можно было поставить за reverse proxy/CDN.

Для реального домена:

1. Добавить домен в Cloudflare и направить DNS-запись на сервер.
2. Включить Proxy (оранжевое облако) для A/AAAA/CNAME сайта.
3. SSL/TLS установить в режим **Full (strict)** после установки сертификата на сервере.
4. Для `/static/*` настроить Cache Rule с длительным кешированием.
5. В Security включить стандартную защиту и rate limiting по необходимости.
6. На сервере выполнить `python manage.py collectstatic`.

Cloudflare настраивается в аккаунте владельца домена, поэтому его нельзя полноценно включить только кодом локального Django-проекта.
