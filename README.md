## Быстрый запуск Prac5

```powershell
git clone https://github.com/Kaimonuri/practicipetrov4kurs.git
cd practicipetrov4kurs\Prac5
docker compose up --build -d
```

После запуска магазин доступен по адресу: <http://127.0.0.1:3001>

### Вход в административную панель

| Поле | Значение |
|---|---|
| Адрес | <http://127.0.0.1:3001/admin> |
| Логин | `lab16` |
| Пароль | См. конфигурацию Prac5 |

## Проверка Docker

```powershell
docker compose ps
docker compose exec web whoami
docker images prac4-store
curl.exe http://127.0.0.1:3001/health
```

Контейнер должен получить состояние `healthy`, а команда `whoami` должна вывести пользователя `app`.


## Запуск Prac6 и Prac7 без Docker

Откройте папку нужной практики:

```bash
cd Prac6
# или: cd Prac7
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
read -rsp "Пароль администратора (от 8 символов): " ADMIN_PASSWORD
echo
export ADMIN_PASSWORD
.venv/bin/python app.py
```

На Windows используйте `py -m venv .venv`, затем `.venv\Scripts\python -m pip install -r requirements.txt`. Перед запуском задайте переменную окружения `ADMIN_PASSWORD`, после чего выполните `.venv\Scripts\python app.py`.

| Практика | Адрес | Логин администратора |
|---|---|---|
| Prac6 — «Корочки.есть» | http://127.0.0.1:8000 | `Admin` |
| Prac7 — «МастерСервис» | http://127.0.0.1:8001 | `Admin` |

При первом запуске автоматически создаются база SQLite, справочник услуг или курсов и учётная запись администратора. Пароль берётся из `ADMIN_PASSWORD` (минимум 8 символов); после создания администратора повторно задавать его не требуется. Пользователи регистрируются через сайт. Рабочие базы, локальные секретные ключи и виртуальные окружения в Git не включены.

Если порт занят, остановите ранее запущенное приложение либо укажите другой порт: `PORT=8002 .venv/bin/python app.py`.
