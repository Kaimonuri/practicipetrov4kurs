# Практические работы по веб-разработке

Репозиторий содержит последовательные версии интернет-магазина мебели. В каждой практической работе проект расширяется новыми возможностями и технологиями.

## Список практических работ

| Практика | Стек | Что было сделано |
|---|---|---|
| [Prac2](./Prac2) | Python, Django, SQLite, HTML, CSS, Bootstrap | Создан базовый интернет-магазин: каталог и карточки товаров, категории, корзина, оформление заказа и административная часть Django. |
| [Prac3](./Prac3) | Python, Django, SQLite, Bootstrap, JavaScript | Магазин расширен регистрацией и авторизацией, профилем пользователя, историей заказов, избранным, отзывами, промокодами, остатками товаров и управлением заказами. |
| [Prac4](./Prac4) | Node.js 24, Express, SQLite, JavaScript, Bootstrap | Проект перенесён на JavaScript и Express. Добавлены серверные сессии, REST API, проверка данных, безопасное хранение паролей, загрузка изображений, роли пользователей и отдельные страницы интерфейса. |
| [Prac5](./Prac5) | Docker, Docker Compose, Node.js 24, Express, SQLite, Alpine Linux | Docker-версия Prac4: многоэтапная сборка, компактный Alpine-образ, запуск от пользователя без root-прав, healthcheck, постоянные volumes для базы и изображений, защита shell-скрипта от CRLF. |

## Быстрый запуск Prac5

```powershell
git clone https://github.com/Kaimonuri/practicipetrov4kurs.git
cd practicipetrov4kurs\Prac5
docker compose up --build -d
```

После запуска магазин доступен по адресу: <http://127.0.0.1:3001>

### Вход в административную панель

| Поле | Значение |
|---|---|
| Адрес | <http://127.0.0.1:3001/admin> |
| Логин | `lab16` |
| Пароль | `prac3` |

## Проверка Docker

```powershell
docker compose ps
docker compose exec web whoami
docker images prac4-store
curl.exe http://127.0.0.1:3001/health
```

Контейнер должен получить состояние `healthy`, а команда `whoami` должна вывести пользователя `app`.
