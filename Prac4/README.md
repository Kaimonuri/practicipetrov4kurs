# Prac4 — JS Store

Новая версия мебельного магазина из Prac3 на Node.js 24, Express и SQLite. Данные каталога, учётные записи, заказ, промокоды и избранное перенесены из `Prac3/db.sqlite3` в `dev.db`. Оригинальный Prac3 не изменялся.

## Запуск

```powershell
cd C:\Users\thean\Projects\practicipetrov4kurs\Prac4
& 'C:\Users\thean\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd' install
Copy-Item .env.example .env
# Замените SESSION_SECRET в .env на случайную строку.
node server.js
```

Откройте http://127.0.0.1:3000/. При первом запуске SQLite-база уже содержит каталог и перенесённые данные. `dev.db` намеренно включена в репозиторий по требованию задания. Для повторного переноса данных из Prac3 используйте `python scripts/import_prac3.py ../Prac3` после запуска `node -e "require('./db')"`. Импорт использует `INSERT OR IGNORE`, поэтому повторный запуск не дублирует записи.

Админ-панель: http://127.0.0.1:3000/admin/; логин `lab16`, пароль `prac3`. Для размещения в сети пароль и секрет сессии нужно заменить. Учетные записи Prac3 импортированы с исходными Django PBKDF2-хешами, поэтому прежние пароли работают.

## Реализовано

- Регистрация с серверной и клиентской проверкой; вход и выход через HttpOnly session cookie.
- Каталог с поиском, фильтрами и сортировкой; публичные `GET /api/products` и `GET /api/products/:id`, кеширование ответа каталога на 60 секунд.
- Корзина с количеством и удалением; промокоды; оформление с доставкой, датой и оплатой; атомарное изменение остатков в SQLite-транзакции.
- История заказов, избранное и отзывы после завершённого заказа.
- Загрузка изображений через Multer в `public/uploads/`; заглушка `no_image.png`; мобильная верстка под ширину 390 px и анимации.
- Админ-панель: фильтр заказов по статусу, массовое изменение статуса, добавление товаров и фото, создание промокодов.

`public/uploads/` исключена из Git. Два исходных изображения Prac3 скопированы туда для локального предпросмотра; после клонирования репозитория товары с отсутствующими фото будут показывать заглушку. Для полноценного переноса файлов запустите импорт ещё раз с доступным Prac3.

Для Cloudflare можно проксировать домен на приложение и кешировать `/public/*` и публичный `GET /api/products`; приватные маршруты и cookie кешировать нельзя. Локальный SQLite и стандартное хранилище сессий Express рассчитаны на учебный одиночный процесс.

## Проверка

```powershell
node scripts/smoke.js
```

Сценарий проверяет каталог, REST API, вход администратора, корзину, заказ, статус и уменьшение остатка; тестовый заказ удаляется после проверки.
